# 第 6 章 · 发布：让别人也能打开

## 这一章要解决的问题

> **本地能跑 ≠ 别人能打开。** 这是小白最常踩的最后一个坑。

## 大纲

### 6.1 先分清三件事

| 概念 | 白话 | 谁能看 |
|---|---|---|
| **本地预览** | 只有你电脑上能开 | 只有你 |
| **局域网** | 同一个 WiFi 下能开 | 同事/家人 |
| **公网部署** | 有个网址，谁都能开 | 所有人 |

**`http://localhost:3000` 发给别人，别人一定打不开。**

### 6.2 发布路径（由易到难）

| 路径 | 难度 | 适合 | 状态 |
|---|---|---|---|
| 静态托管（纯前端页面） | ⭐ | 小游戏、小工具 | 待补 |
| 容器/服务器部署 | ⭐⭐⭐ | 需要后端、数据库 | 待补 |

> 现有经验可复用：claw VPS 部署流程（见 `claw-server-deployment` skill）

### 6.3 发布前检查清单

- [ ] 手机上打开过（不只是电脑上）
- [ ] 换一个浏览器打开过
- [ ] 关掉本地服务后，网址还能打开（证明真的部署了，不是本地）
- [ ] 页面标题、图标改成了自己的
- [ ] 没有把自己的密钥/密码写进代码

### 6.4 让 AI 帮你发布

```
我要把这个项目发布到公网，让别人能通过一个网址打开。
请告诉我：
1. 我这个项目属于哪种类型（纯前端 / 需要后端）
2. 推荐最简单的发布方式
3. 每一步我应该看到什么
```
