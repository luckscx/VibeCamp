# 第 0 章 · 开始之前

## 这一章要解决的问题

小白最常见的三种劝退：
1. **预期过高** —— 以为说一句话就能出个完整的游戏，结果失望
2. **预期过低** —— 以为要先学半年编程，还没开始就放弃
3. **不知道边界** —— 不知道哪些事 AI 能做、哪些必须自己决定

## 大纲

### 0.1 AI 现在能帮你做到哪一步
- 能：把一个描述清楚的想法变成能跑的东西
- 能：看懂报错并给出修改方案
- 不能：替你决定"这个游戏好不好玩"
- 不能：在没有明确描述的情况下猜对你的审美

### 0.2 你需要付出什么
- **时间**：第一个能跑的小游戏，通常几小时到几天
- **耐心**：平均要来回 5-20 轮对话
- **决策**：玩法、美术风格、难度曲线 —— 这些 AI 替不了

### 0.3 一条重要的心理准备
> AI 会"失忆"。它不是在跟你聊天，是在读一份**会被压缩的文档**。
> 所以重要的东西要写进文件，不能只靠"它应该记得"。

### 0.4 本训练营的使用方式
- 主线章节按顺序读
- 资源库按需查
- 卡住了先翻第 05 章
