# 发布上线

## 先确认一件事

> **`http://localhost:3000` 发给别人，别人一定打不开。**
> "localhost" 的意思就是"我自己的电脑"。

## 提示词

```
我要把这个项目发布到公网，让任何人通过一个网址都能打开。

请告诉我：
1. 我这个项目属于哪种类型（纯前端静态页面 / 需要后端服务）
2. 针对我的情况，最简单的发布方式是什么
3. 分步骤告诉我怎么做，每一步我应该看到什么

我完全没部署过，请把每一步都写清楚。
```

## 发布前自检（让 AI 一起过一遍）

```
发布前请帮我检查：
1. 有没有把密钥/密码/token 写进代码里（有的话指出来）
2. 在手机上能正常显示吗（有没有写死电脑端尺寸）
3. 关掉本地服务后，网址还能打开吗（证明真的部署了）
4. 页面标题和图标是我自己的吗
```

## 发布后验证

- [ ] 用**手机**打开过（不只是电脑）
- [ ] 用**另一个浏览器**打开过
- [ ] **关掉本地服务**后网址还能打开
- [ ] 发给一个朋友，确认他能打开

## 常见坑

| 现象 | 原因 |
|---|---|
| 自己能开，别人不能 | 只跑了本地服务，没真正部署 |
| 部署后页面空白 | 路径配置问题（`base` 路径不对） |
| 刷新后 404 | 路由模式问题，需配置重定向 |
