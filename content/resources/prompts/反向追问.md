# 反向追问

**这是整个训练营最有用的一条提示词。**

## 提示词

```
我要做一个 [一句话描述]。

在动手之前，请先问我 10 个问题，帮我把这个想法想清楚。
问题的范围包括：玩法/流程、用户会怎么用、需要哪些功能、
风格偏好、有什么是我没想到的坑。

一次问完，我逐条回答。问完等我回复，不要开始写代码。
```

## 为什么有用

- **你不知道该说什么，但 AI 知道。** 做这类东西需要哪些决策点，AI 清楚。
- 你只需要回答选择题，不用自己憋出一份需求文档。
- 回答完 10 个问题，需求自然就清楚了。

## 变体

### 想做游戏
```
我要做一个小游戏：[一句话描述]。

在动手前先问我 10 个问题，重点帮我确定：
- 核心玩法循环（玩家反复做什么）
- 失败条件和胜利条件
- 难度怎么递进
- 大致的美术风格

一次问完，等我回复再动手。
```

### 想做应用
```
我要做一个小应用：[一句话描述]。

在动手前先问我 10 个问题，重点帮我确定：
- 用户要完成的核心流程是什么
- 数据存在哪（本地 / 云端）
- 要不要登录
- 有哪些功能先不做

一次问完，等我回复再动手。
```

## 回答完之后的收尾

```
我回答完了。请把我们讨论的结果整理成一份需求文档，
存到 BRIEF.md，然后告诉我你打算怎么做，等我确认再动手。
```

> **一定要让它存成文件。** 后面 AI 失忆时，读文件就能想起来。
