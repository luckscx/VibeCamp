# 报错求助

## 模板

```
报错了。

【我做了什么】点了"开始游戏"按钮
【期望看到】进入游戏画面
【实际看到】页面卡住，控制台红色报错

【完整报错】
（整段复制，从第一行到最后一行）

【相关文件】如果你知道是哪个文件，贴文件名
```

## 怎么拿到完整报错

**浏览器（页面报错）：**
1. 按 `F12`（Mac：`Cmd + Option + I`）
2. 切到 **Console** 标签
3. 找到红色文字
4. **右键 → 复制全部**，不要手动只截一行

**终端（命令行报错）：**
- 从报错的第一行开始选，一直选到提示符回来之前
- 整段复制

## 三个不要

- ❌ **不要只贴最后一行** —— 前面的堆栈信息才是定位关键
- ❌ **不要自己删改报错内容**
- ❌ **不要只说"还是不行"** —— 必须给新信息（新的报错 / 你又试了什么）

## 改了几轮还没好

```
这个问题你已经改了 3 轮还没解决。请停下来，
重新分析一下根本原因是什么，而不是继续试。
如果你不确定，请直接说不确定，我们换个思路。
```

> 连续 3 轮没进展 → 直接用止损三板斧，见第 5 章。
