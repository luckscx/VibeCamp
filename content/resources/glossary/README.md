# 术语表

> 白话对照。看不懂的词来这里查。

## 环境 & 命令

| 术语 | 白话 |
|---|---|
| **终端 / Terminal** | 一个黑窗口，你打字、电脑执行。不是黑客专用，就是个输入框 |
| **命令行 / CLI** | 在这个黑窗口里用的工具（CodeBuddy Code 就是 CLI） |
| **npm** | 装工具的工具。类似手机上的应用商店 |
| **Node.js** | 让电脑能跑 JavaScript 的东西。很多 AI 工具依赖它 |
| **PATH** | 电脑去哪些文件夹里找命令。命令找不到通常是它没配好 |
| **Git Bash** | Windows 上模拟 Linux 命令行的小工具，**CodeBuddy 在 Windows 上必须装** |
| **PTY** | 虚拟终端。有些命令行程序必须在真实终端环境里才能正常交互 |
| **环境 / Environment** | 跑代码需要的一整套东西：操作系统、Node 版本、装了哪些库 |

## 开发过程

| 术语 | 白话 |
|---|---|
| **仓库 / repo** | 你的项目文件夹（加了版本管理之后叫仓库） |
| **commit / 提交** | 给当前进度拍个快照，随时能退回来 |
| **依赖 / dependencies** | 你的项目用到的别人写好的代码包 |
| **端口 / port** | 一台电脑上不同服务的门牌号，比如 `3000` |
| **localhost** | "我自己的电脑"。**发给别人别人打不开** |
| **预览** | 只有你自己能看的运行效果 |
| **部署 / deploy** | 放到公网上，让别人也能打开 |
| **热更新** | 改完代码页面自动刷新，不用手动重启 |
| **Git** | 代码版本管理工具，能记录每次改动、随时回退（像游戏的存档点，打坏了可以读档重来） |
| **README** | 项目说明文件，告诉别人（和三个月后的你）这项目怎么跑起来、怎么改 |
| **构建 / Build** | 把开发时的一堆文件打包压缩成能直接部署的成品（像把食材做成能端上桌的菜） |
| **dist** | 构建后生成的目录，里面就是要部署上线的东西 |
| **重构 / Refactor** | 不动功能的前提下整理代码结构，让它更好读更好改（房间东西没变，只是重新收纳了一遍） |
| **MVP** | 最小可用版本。只做核心功能，能用就先上，别追求完美（先做个能骑的滑板车，别一上来就造汽车） |
| **localStorage** | 浏览器提供的一小块存储空间，存在用户自己电脑上，刷新不丢，换设备就没了 |
| **状态 / State** | 程序当前的数据快照。比如游戏里「分数 120、血量 3、暂停中」就是状态 |
| **响应式 / Responsive** | 页面能自动适应不同屏幕尺寸，手机和电脑都能正常显示 |
| **Canvas** | 网页上用来画图、做动画、做游戏的一块「画布」 |
| **API** | 别人做好的功能，你按规定方式调用就能用（像餐厅菜单，点菜就行，不用管厨房怎么做） |
| **CDN** | 别人托管好的公共库，你一行代码引用就能用，不用自己下载 |
| **404** | 找不到你要的东西，最常见的原因是文件路径写错了 |

## AI 相关

| 术语 | 白话 |
|---|---|
| **上下文 / context** | AI 当前"记得"的内容。**有上限，满了会压缩** |
| **token** | AI 处理文字的计量单位，约等于字数。要花钱 |
| **会话 / session** | 你跟 AI 的一轮对话。**只存在本地，不能跨设备同步** |
| **压缩 / compact** | 上下文快满时，AI 把前面的内容总结成摘要。**会丢细节** |
| **幻觉 / hallucination** | AI 一本正经地编造不存在的东西 |
| **Agent / 智能体** | 能自己规划、调用工具、完成任务的 AI（不只是聊天） |
| **Skill** | 给 AI 的"专业培训包"，**AI 会自己判断什么时候用** |
| **斜杠命令** | 你自己定义的 `/xxx` 快捷提示词，**要手动输入才触发** |
| **子代理 / Sub-Agent** | 封装好的一个"角色"，可以被调用去干活 |
| **MCP** | 让 AI 连接外部工具/数据的通用接口 |
| **Vibe Coding** | 不写代码，用说话的方式做软件。你描述想要什么，AI 写代码，你负责看结果对不对（像跟装修队说「我要北欧风、要个大书架」，而不是自己画施工图） |
| **Prompt** | 你跟 AI 说的话 / 下的指令 |
| **Bug** | 程序里出错的地方，导致行为不符合预期 |
| **Debug** | 找 bug 并修掉的过程 |
| **CodeBuddy** | 腾讯自研的编程 Agent，能读代码库、改代码、跑验证，端到端把软件做出来 |
| **WorkBuddy** | 腾讯的 AI 办公工作台，处理文档、表格、数据这类办公任务，不擅长做软件工程 |

## CodeBuddy 专属

| 术语 | 白话 |
|---|---|
| **`/init`** | 让 AI 先扫描一遍项目，建立了解。**能省 30-50% token** |
| **`CODEBUDDY.md`** | 项目记忆文件，写长期约定。**防失忆的关键** |
| **Craft 模式**（WorkBuddy） | AI 可以直接改你的文件 |
| **Ask 模式**（WorkBuddy） | AI 只读不写，更安全 |
| **积分 / Credits**（WorkBuddy） | 消耗计费单位。新用户送 5000，每日签到 100 |

## 排错

| 术语 | 白话 |
|---|---|
| **报错 / error** | 程序告诉你"我干不下去了，因为 XXX"。**是线索，不是失败** |
| **堆栈 / stack trace** | 报错时那一长串文字，**最上面和最下面最关键** |
| **控制台 / Console** | 浏览器里看报错的地方，按 F12 打开 |
| **缓存 / cache** | 浏览器存的旧版本。改了没生效常因为它，硬刷新试试 |
| **回滚 / rollback** | 退回上一个能用的版本 |
