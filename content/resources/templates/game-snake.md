# 模板 · 贪吃蛇

> ⚠️ **状态：草稿**。本模板的提示词尚未实机跑通，第一次用请把它当作「起点」而不是「保证能成」。
> 如果 AI 做出来的和下面写的验收点不一致，以**你实际看到的**为准，然后按第 4 章的方式提修改。

## 一句话描述

一个在浏览器里用方向键玩的贪吃蛇，吃到食物变长加分，撞墙或撞自己就结束。

## 完整需求

```markdown
# 贪吃蛇

## 一句话
我要做一个贪吃蛇游戏，用来在浏览器里打发时间。

## 给谁用
我自己，以及我发给链接的朋友。

## 怎么用
1. 打开页面，看到深色背景中间一个方形网格，一条蛇在慢慢移动
2. 我按方向键，蛇会转向
3. 蛇头碰到红点（食物），分数 +10，蛇变长一格，红点换位置
4. 蛇撞到墙壁或自己的身体，游戏结束，显示最终分数和"再来一局"

## 必须有的功能
1. 方向键控制上下左右（不能反向直接掉头）
2. 实时显示当前分数、最高分
3. 游戏结束后能一键重开
4. 最高分存浏览器本地，关掉页面再打开还在

## 明确不要的
1. 不要登录、排行榜、多人对战
2. 不要音效（第一版不做）
3. 不要手机触屏操作（先只做键盘）
4. 不要关卡、道具、皮肤系统

## 风格参考
- 深色背景 #1a1a1a，蛇是绿色 #4ade80，食物是红色 #ef4444
- 网格线用很淡的灰色，别抢视线

## 技术偏好
- 单个 HTML 文件，双击就能玩，不用装任何东西
- 数据存 localStorage
```

## 建议的第一句话

```markdown
我要做一个贪吃蛇游戏，完整需求见上面的"完整需求"部分。

在动手之前，请先问我 5 个问题，确认你没理解错的地方。
一次问完，我逐条回答。问完等我确认再开始写代码。

代码要求：
- 单个 HTML 文件，双击就能在浏览器打开玩
- 用 Canvas 画游戏画面，不要用一堆 div 拼
- 关键逻辑（移动、碰撞、生成食物）要有中文注释
- 我是零基础，注释请解释"为什么这么做"，不要只写"这是什么"

做完请告诉我：
1. 怎么打开（双击哪个文件）
2. 我该看到什么画面
3. 哪些功能现在能试
```

## 验收点

照着走一遍，全部通过才算做完：

- [ ] 双击 HTML 文件，浏览器里出现游戏画面（不是一片白）
- [ ] 按方向键，蛇会转向，且**不能直接反向掉头**（比如正往右走时按左键无效）
- [ ] 吃到食物，分数 +10，蛇**变长一格**
- [ ] 撞墙后游戏结束，出现最终分数和"再来一局"按钮
- [ ] 点"再来一局"，分数归零，重新开始
- [ ] **关掉浏览器再打开**，最高分还在

> 最后一条最容易漏。很多 AI 第一版会忘记存最高分，或者存了但读的时候写错了。
> 验收时一定要真的关掉页面再开一次，别只是刷新。

## 做完之后还能加什么

按「一次只加一个」的顺序来：

1. 空格键暂停 / 继续
2. 难度递增：每吃 5 个食物，速度加快一档
3. 音效（用 Web Audio 生成，不用音频文件）
4. 手机触屏滑动操作
5. 障碍物关卡

## 这个模板教了什么

- **"不能直接反向掉头"是游戏规则的一部分** —— 你不说，AI 大概率不做，
  然后你会发现蛇能瞬间掉头穿过自己，游戏就没难度了
- **"关掉再打开"是验收的最后一关** —— 刷新页面和重开浏览器是两回事，
  前者可能只是内存里的值没清，后者才真正考验持久化
