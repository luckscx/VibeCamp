# 模板 · 抽签 / 转盘

> ⚠️ **状态：草稿**。提示词尚未实机跑通，请以实际结果为准。

## 一句话描述

一个能自定义选项的随机抽签工具：自己填几个选项，点一下随机选一个出来。

## 为什么它适合当第一个"工具"

- **逻辑极简**：核心就是一个随机数
- **反馈即时**：点一下立刻有结果，不需要调试半天
- **真的有用**：中午吃什么、谁去拿外卖、抽奖，日常就能用上

做它的意义不在技术，在于**体验一下"从想法到能用"的完整闭环**。

## 完整需求

```markdown
# 随机抽签工具

## 一句话
我要做一个抽签网页，用来在自己填的选项里随机选一个。

## 给谁用
我自己，以及聚餐时决定谁买单的场合。

## 怎么用
1. 打开页面，看到左侧一个文本框（每行一个选项），右侧一个大大的"开始"按钮
2. 我在文本框里每行写一个选项
3. 点"开始"，中间的区域快速轮播这些选项
4. 大约 2 秒后停下来，高亮显示最终选中的那个

## 必须有的功能
1. 文本框输入选项，每行一个
2. 点"开始"，有滚动/轮播的动效（不是直接跳结果）
3. 2 秒左右后停下，高亮最终结果
4. 能再点一次重新抽
5. 默认给几个示例选项，打开就能试

## 明确不要的
1. 不要登录、不要保存历史记录
2. 不要"排除已抽中"的功能（第一版每次都从全部里抽）
3. 不要权重设置（每个选项概率相同）
4. 不要音效（第一版不做）
5. 不要分享链接功能

## 风格参考
- 深色背景 #111827，卡片 #1f2937
- 结果高亮用橙色 #f59e0b
- 字要大，结果区域字号 48px 以上

## 技术偏好
- 单个 HTML 文件，双击就能用
```

## 建议的第一句话

```markdown
我要做一个随机抽签网页，完整需求见上。

在动手之前，请先问我 5 个问题。特别确认：
- 选项为空或只有一个时，点"开始"会发生什么
- 滚动动效怎么实现比较流畅

一次问完，我逐条回答。问完等我确认再写代码。

代码要求：
- 单个 HTML 文件，双击就能用
- 中文注释
- 我是零基础

做完请告诉我怎么打开、该看到什么、怎么验证。
```

## 验收点

- [ ] 打开就能看到几个默认选项，不用配置就能点"开始"试
- [ ] 改文本框里的选项，抽奖结果跟着变
- [ ] 点"开始"有**滚动动效**，不是瞬间出结果
- [ ] 2 秒左右后停下，结果**高亮**显示
- [ ] 连点 5 次，结果不是每次都一样（说明真的随机）
- [ ] **清空文本框后点"开始"**，不会白屏或报错（应该给出提示）

> 最后一条是这个工具最容易翻车的地方。AI 通常只处理"有选项"的情况，
> 空输入时 `Math.random()` 拿不到东西，页面就崩了。

## 做完之后还能加什么

1. 抽中后从候选里移除（适合抽奖不重复的场景）
2. 转盘模式（画个真转盘，指针转）
3. 音效（用 Web Audio 生成，不用音频文件）
4. 选项存本地，下次打开还在
5. 一次抽多个（"抽 3 个人"）

## 这个模板教了什么

- **"打开就能试"是最好的默认状态** —— 要求 AI 预置几个示例选项，
  你打开就能看到效果对不对，不用先想数据
- **动效是"感觉对不对"的关键** —— 技术上瞬间出结果完全正确，
  但没人会觉得那是"抽奖"。想要感觉，就得说清楚
