> 改这里的 markdown 就会同步过去。

## 怎么用

1. 找到跟你想要的东西最接近的一条
2. **整段复制**，不要自己改着改着改漏了
3. 把 `[中括号]` 里的内容换成你的
4. 粘给 AI，等它问你问题（模板里都写了"先问我 10 个问题"——别跳过）

## 两条使用原则

**原则一：先抄，再改。**

第一次原样复制、不改任何东西。跑通了，第二次再开始调。
一开始就自己改，出问题你不知道是改坏了还是模板有问题。

**原则二：模板里的"不要什么"比"要什么"更重要。**

每个模板末尾都有一节"不要做什么"。那几行是踩过坑才写上去的。
删掉它们，AI 大概率会做出一个能跑但很烦人的东西。
