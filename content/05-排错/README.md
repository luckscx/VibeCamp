# 第 5 章 · 排错：报错了怎么办

## 这一章要解决的问题

报错就慌，只会来回贴报错，越改越乱。

## 核心心法

> **报错不是失败，是 AI 最擅长处理的东西。**
> 真正危险的不是报错，是"改了 20 轮还是不对"却舍不得重来。

## 大纲

### 5.1 排错决策树
```
出错了
  │
  ├─ 页面打不开（白屏 / 连不上）
  │    └─ 服务没起来？端口被占？→ 看 5.2
  │
  ├─ 能打开，但某个功能点了没反应
  │    └─ 打开浏览器控制台（F12）看红色报错 → 整段复制给 AI
  │
  ├─ 报错信息 AI 看不懂 / 改了没用
  │    └─ 上下文已经乱了 → 用止损三板斧（5.4）
  │
  └─ 改了 3 轮以上还在同一个地方打转
       └─ 停下来，这是需求没说清，回第 3 章
```

### 5.2 常见症状速查表

| 症状 | 可能原因 | 第一动作 |
|---|---|---|
| 白屏 | 服务没起 / 端口错 | 问 AI："服务在哪个端口跑？" |
| `port already in use` | 端口被占 | 换端口或杀掉旧进程 |
| `command not found` | 工具没装 / PATH 问题 | 见第 2 章 2.3 |
| `Cannot find module xxx` | 依赖没装 | 让 AI 跑安装命令 |
| 改了代码页面没变 | 缓存 / 没热更新 | 硬刷新（Ctrl+Shift+R） |
| 本地能跑，别人打不开 | 只跑了本地服务 | 见第 6 章 |

### 5.3 怎么把报错贴给 AI（模板）

```
报错了。

【我做了什么】点了"开始游戏"按钮
【期望】进入游戏画面
【实际】页面卡住，控制台红色报错
【完整报错】
（整段复制，不要只截一行）

【相关文件】如果你知道是哪个文件，贴文件名
```

三个 **不要**：
- ❌ 不要只贴最后一行（前面的堆栈信息才是关键）
- ❌ 不要自己删改报错内容
- ❌ 不要说"还是不行"而不给新信息

### 5.4 止损三板斧（改不动了就用）

**重要：这不是认输，是专业做法。**

| 招式 | 什么时候用 | 怎么做 |
|---|---|---|
| **1. 回滚** | 刚改完就坏了 | "撤销你刚才那次改动" |
| **2. /clear** | 改了 3 轮还在原地打转 | 敲 `/clear`，记忆文件还在，不会丢 |
| **3. 新开目录** | 整个方向乱了 | 新建文件夹，只把 `BRIEF.md` 和 `PROGRESS.md` 带过去，重新 `/init` |

**判据：连续 3 轮没有实质进展 → 立刻止损。**

### 5.5 预防胜于治疗

- 每跑通一步就让 AI 生成/更新 `PROGRESS.md`
- 长会话定期 `/compact`
- 大改动前先让 AI 说它打算怎么改

## 验收点

- [ ] 遇到报错不慌，能按决策树判断属于哪一类
- [ ] 知道止损的判据（连续 3 轮没进展）
- [ ] 会贴完整报错
