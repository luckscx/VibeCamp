## 写作约束

1. **不编 API** —— 每个命令、路径、参数必须有出处，拿不准标 `待验证`
2. **每步有验收点** —— 写"你应该看到 X"，不写"然后就成功了"
3. **中文优先** —— 术语首次出现给白话解释
4. **反面案例要真** —— 报错信息贴真实样本，不编造
5. **零门槛 ≠ 零思考** —— 标出哪些决策 AI 替不了
6. **案例要能溯源** —— 必须标注来源仓库 + commit 号
7. **配图优先** —— 有图能说清的就不纯用文字
